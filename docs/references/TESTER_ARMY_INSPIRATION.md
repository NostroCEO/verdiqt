# TesterArmy Inspiration Boundary

Status: runtime pattern audit completed 2026-08-26 with Playwright against `https://tester.army/` at 1440 x 1000. This is a visual-reference record, not a source or asset import.

## Public patterns observed

- Flat near-black hero inside a 1280 px rail-bound shell at the 1440 px viewport.
- Sticky header approximately 73 px high.
- Oversized 60 px headline with a 68 px line height, short supporting copy, and two sharp actions.
- One-pixel neutral borders, square geometry, mono uppercase system labels, and deliberate negative space.
- A dense supporter or customer matrix immediately after the hero, using 80 px rows separated by one-pixel gaps.
- Product storytelling organized as numbered sections, a three-stage interactive demo, and dashboard-plus-terminal compositions.
- Most interaction transitions fall between 150 and 300 ms. A longer orchestrated product loop runs around eight seconds, with a roughly 1.1 second caret cadence.

## Original Verdiqt interpretation

- Verdiqt uses its own periwinkle accent, courtroom copy, evidence model, and WebMCP product story.
- The reference skull is replaced by an original CSS halftone gavel and original crosshair geometry.
- The sign-up actions are replaced by an accessible public GitHub repository or SaaS idea intake preview.
- The customer-logo matrix is replaced by text-only names from the official WebMCP Challenge supporter resource hub with a visible non-endorsement disclosure.
- The product demo is an original three-stage trial proceeding with an original SVG evidence route and finite Motion sequences.
- The light section is Verdiqt's procedural record surface, not a copied screenshot or page fragment.

## Prohibited reuse

- Do not copy tester.army source code, CSS class systems, exact copy, SVG path data, skull artwork, logos, customer marks, testimonials, screenshots, or branded assets.
- Do not present tester.army customers as Verdiqt customers or supporters.
- Do not use the reference as proof of Verdiqt functionality.
- Keep future inspiration at the level of layout rhythm, interaction principles, computed dimensions, and general visual techniques.

## Verification record

- The reference console showed authentication-related cross-origin failures only; those failures were not copied or reproduced.
- The reference DOM contained 120 inline SVG elements and 47 SVG image assets. Only counts, dimensions, labels, and composition categories were inspected. Path data and files were not copied.
- The reference runtime exposed an eight-second product sequence with grouped opacity events and standard 150 to 300 ms transitions. Verdiqt uses shorter finite sequences and explicit replay to preserve accessibility.
